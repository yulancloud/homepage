做了个功能？三步上架到市场

不需要服务器、不需要数据库。GitHub 的模板仓库负责「一键建仓」，Issue 表单负责「收集提交」，市场页只负责读取清单 —— 这就是插件能一直存在 GitHub 上的原因。

1

用模板仓库建插件

在模板仓库点绿色 Use this template，一键创建同结构仓库。按「功能自定义」教程加功能，写好 plugin.json 与给小白看的 INSTALL.md。

打开模板仓库 →
2

打包 zip 放到自己仓库

跑 ./pack.sh 打包，把 zip 上传到你自己 GitHub 仓库的 Release（或仓库内文件），得到一个公开直链。本体始终在你自己的仓库里。

看提交规范 →
3

点「上传插件」填表单

填名称、简介、zip 直链等信息提交为一个 Issue。审核通过后会合并进索引仓库的 plugins.json，市场页下次加载自动出现。

提交插件 →

装之前，先知道这几件事

插件是官方做的吗？安全吗？

市场里的插件由社区提交，带「已验证」标记的经过官方人工检查。装之前先看仓库源码与 INSTALL.md，务必先备份 config/ 和 data/shop.sqlite。

装完没效果 / 打不开怎么办？

先看 小白安装教程 的验证与常见问题；运行目录没指向 public/ 是最常见的 404 原因，见 部署总览。

怎么卸载、怎么回滚？

每个插件的 INSTALL.md 都写了卸载步骤：删掉新增文件、撤销合并、恢复版本号即可。出问题时用安装前的备份整体覆盖回去，见 安装与升级。
