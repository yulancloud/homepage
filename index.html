FEATURES · 核心能力

从商品上架到自动交付，一条链路走完

不依赖 MySQL，不需要常驻队列，一台能跑 PHP 的主机即可部署。欲蓝魔方相关的敏感凭据只在服务端流转。

魔方云（KVM）

对接魔方云 RESTful API，支付后自动创建云主机并交付 IP、系统、配置与一次性密码；用户可自助开机、关机、重启、重置密码。

自动开云主机 · 自助管理

魔方财务 · 对接上游

像智简魔方财务那样对接上游：可维护多条命名上游、同步上游产品目录、加价销售，订单支付后自动在上游创建订单开通，账号与连接信息直接交付到用户中心。

同步产品 · 加价销售 · 上游开通

工单系统

用户可提交工单、追加回复、关联订单；后台客服受理、回复与客户状态流转。严格归属校验，用户只能看到自己的工单。

用户提单 · 客服受理

支付与订单

对接易支付，异步回调严格验签并校验状态、通道与金额完全相等，具备幂等处理；支持免费直付、订单状态流转与发货管理。

易支付 · 无法伪造回调

完整后台

商品、分类、订单、评价、站点设置与运费、账号限购、IP 限制、操作日志。商品表单内置类型选择框，编辑与新增都可切换类型。

店主角色 · 细粒度校验

安全与可运维

全站参数化查询、CSRF 同源校验、会话只存令牌哈希、用户输入统一转义。/api/health 可校验版本号，迁移脚本幂等且能自动修复旧库。

无高危漏洞 · 健康检查

用户中心（v1.4 增强）

用户中心包含我的订单、控制台、我的云主机、工单、余额与账户设置。云主机可自助管理；工单可提单与查看回复。所有敏感信息按归属隔离，口令不落库、不进日志明文。

云主机管理 · 工单 · 归属隔离

主题 / 插件上传（v1.2 新增）

后台上传一个 zip 就能换主题、装插件，支持启用、停用与卸载。主题只覆盖 CSS 变量，升级不丢；插件零侵入、不建表。也可到插件市场下载分享。

后台上传 · 免改核心文件

WORKFLOW · 交付流程

买家付完款，剩下的系统自己做完

01

下单并支付

买家选购魔方云 / 魔方财务商品，¥0 商品免费直付，其余走易支付或余额支付并等待验签回调。

02

匹配上游

服务端按商品绑定的上游与上游产品，使用 API 密钥请求对应的上游接口。

03

上游自动开通

在上游创建订单 / 云主机并用余额付款，拿到 IP、账号与一次性密码；失败则支付回滚。

04

交付与自助管理

交付页展示连接信息，密码仅此一份；用户可在「我的云主机」自助管理，遇到问题提交工单。

QUICK START · 部署

三步跑起来

Apache 用项目自带 .htaccess，无需填伪静态；Nginx / 宝塔需粘贴一段规则。

1
上传并覆盖文件
解压系统包到站点目录，把 Web 运行目录设为 public/，确认 PHP 8.3 与 SQLite 扩展可用。
2
配置伪静态（Nginx / 宝塔）
在站点「伪静态」框粘入右侧规则，让 /api/ 走 api/index.php；Apache 可跳过此步。
3
执行迁移并清缓存
运行 php bin/migrate.php（幂等，自动修复旧库），然后 Ctrl+F5 强刷，访问 /api/health 确认版本号。
nginx · 伪静态
# /api/ 统一交给前端控制器
location /api/ {
    try_files $uri /api/index.php$is_args$args;
}

# 后台 / 控制台 / 安装页补结尾斜杠
location ~ ^/(admin|console|install)$ {
    rewrite ^/(.*)$ /$1/ permanent;
}
location = /install/ { try_files /install.html =404; }
location ^~ /admin/ {
    try_files $uri $uri/ /admin/index.html =404;
}
location ^~ /console/ {
    try_files $uri $uri/ /console/index.html =404;
}

# 升级后必跑（幂等）
$ php bin/migrate.php
# 验证版本
$ curl https://你的域名/api/health
